## Cracking the unknown 0x440ff000 observations

**Note: the following DMAC is used to transfer data between the scratchpad at 0x44000000 and the ME local EDRAM or main RAM. It is also used to transfer VME memory context intended to update the Datapath.**

| Address    | R/W | Description |
|------------|-----|-------------|
| 0x440ff000 | RW  | Status |
| 0x440ff004 | RW  | Config / state / routing (observed values: 0x0, 0x31B, 0x831B, 0x1031B, 0x1831B) |
| 0x440ff008 | RW  | Control |
| 0x440ff00c | --  | Unknown |
| **Outer AGU** | | |
| 0x440ff010 | RW  | External address for READ or WRITE, depending on the control value |
| 0x440ff014 | RW  | First outer count, second outer count, minus 1 word (4 bytes) to be transferred |
| 0x440ff018 | RW  | Internal READ or WRITE word offset, depending on the control value |
| 0x440ff01c | -W  | Clear mode |
| **First Inner AGU** | | |
| 0x440ff020 | RW  | Internal READ or WRITE word offset, depending on the control value |
| 0x440ff024 | RW  | First count, second count, minus 1 word (4 bytes) to be transferred |
| 0x440ff028 | RW  | First gap/step, second gap/step |
| 0x440ff02c | RW  | Constant fill value / config / offset |
| **Second Inner AGU** | | |
| 0x440ff030 | RW  | Internal READ or WRITE word offset, depending on the control value |
| 0x440ff034 | RW  | First count, second count, minus 1 word (4 bytes) to be transferred |
| 0x440ff038 | RW  | First gap/step, second gap/step |
| 0x440ff03c | --  | Unknown |
| 0x440ff040 | -W  | Unknown |

### Status
0x800 VME execution done
0x200 Scratchpad transfer/process done
